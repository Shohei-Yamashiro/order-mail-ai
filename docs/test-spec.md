# テスト仕様書（発注メール AI 仕分け）

このファイルは `scripts/TestReport.cs` がテストコードの説明（`[Spec]` 属性）から自動で作ります。直接編集せず、テストの `[Spec]` を直してください。
最新の実行結果は、`scripts/publish.ps1` を実行すると `OrderMail-latest/test-report.md` に出力されます。CI では成果物 `test-report` に保存されます。

## 1. 目的と範囲

業務ロジック（`src/OrderMail.Core`）が仕様どおりに動くことを、自動テスト（xUnit）で確認します。
AI の接続先は偽の HTTP サーバーに置き換え、DB はテストごとに一時フォルダの SQLite を使うので、外部の環境がなくても同じ結果になります。
テストデータには `samples/mails` のサンプルメール 20 通と、正解ラベル `samples/labels.json` を使います。

### 自動テストの対象外（手動で確認する項目）

| 項目 | 確認方法 |
|---|---|
| 画面の表示と操作（Blazor） | `OrderMail-latest/OrderMail.exe` を起動してブラウザで操作する |
| 実際の AI（Ollama・Gemini など）での読み取り精度 | 設定画面の「確認済みメールで評価」で、確定済みメールとの一致率を見る |
| IMAP サーバーからの取り込み | 設定画面の「接続テスト」と「取り込み・解析」 |
| 配布用 zip の展開と起動 | `scripts/publish.ps1` の実行後に exe を起動する |

### 2.3 AI 連携（OpenAI 互換 API）

| ID | 項目 | 確認内容 | ケース数 |
