発注メール AI 仕分け
====================

■ 起動
  OrderMail.exe をダブルクリックすると、ブラウザで画面が開きます（http://localhost:5080）。
  黒いウィンドウ（サーバー）を閉じるとアプリが終了します。
  インストールは不要です。.NET などを入れる必要もありません（Windows 10 / 11 の 64 ビット版）。

■ 試し方
  1. 「受信メール」画面の「取り込み・解析」を押す
     → samples\mails にあるサンプルメール 20 通を取り込み、発注かどうかを判定します。
  2. 「要確認」のメールを開き、発注内容を直して「発注として登録」または「発注ではない」を押す
  3. 「発注一覧」で登録された発注を確認する

■ AI の接続
  初期設定は AI を使わない「ルールベース」です。
  「設定」画面で OpenAI 互換 API（Azure OpenAI・OpenAI・Gemini・Ollama・LM Studio など）を指定すると AI で解析します。
  Azure OpenAI は、エンドポイントに https://<リソース名>.openai.azure.com/openai/v1、モデルにデプロイ名を入力します。
  「テスト解析」ボタンで接続を確認できます。

■ データ
  data フォルダに保存されます（ordermail.db：受信メールと発注、settings.json：設定）。
  data フォルダを消すと初期状態に戻ります。
  API キーとパスワードは Windows のユーザーごとに暗号化して保存します。

■ ポートを変える
  appsettings.json の "Urls" を書き換えてください（例: "http://localhost:5090"）。
