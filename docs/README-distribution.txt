発注メール AI 仕分け（OrderMail）
================================

届いたメールの中から発注メールを見分け、品名・数量・単価などを発注一覧にまとめるアプリです。
判断に迷うメールだけを人が確認し、直した内容は次の判断に活かされます。

ご利用の前に、利用条件（LICENSE.txt）をお読みください。
画像付きの説明は、同じフォルダの「発注メールAI仕分け（OrderMail）のご紹介.pdf」にあります。

このアプリは、作者が AI コーディングエージェント（Cursor）と協働して開発しました。
要件と設計の判断、動作の確認は作者が行い、コードの作成は主に AI エージェントが担当しています。

■ 動作環境
  Windows 10 / 11（64 ビット版）
  インストールは不要です。.NET などを別に入れる必要もありません。
  画面はパソコンに入っているブラウザ（Edge、Chrome など）で表示します。

■ 起動
  1. ダウンロードした zip ファイルを右クリックし、「すべて展開」を選んで展開します。
     （zip のまま中の OrderMail.exe を開くと、正しく動きません）
  2. 展開したフォルダの OrderMail.exe をダブルクリックします。
  3. 黒いウィンドウが開き、続けてブラウザで画面が開きます（http://localhost:5080）。
  4. 「デモアプリについて」のお知らせが出るので、内容を確認して「確認しました」を押します。
     （ブラウザのタブを開き直すと、もう一度表示されます）

  初めて起動するとき、「Windows によって PC が保護されました」という警告が出ることがあります。
  「詳細情報」を押し、表示された「実行」を押してください。
  本ソフトウェアには発行元を証明する電子署名を付けていないため、この警告が出ます。
  展開する前に zip ファイルを右クリック →「プロパティ」→「許可する」にチェック →「OK」とすると、
  この警告が出なくなる場合があります。
  画面はご自身のパソコンの中だけで表示し、他のパソコンからは接続できません。

■ 終了
  黒いウィンドウを閉じると終了します。ブラウザの画面を閉じただけでは終了しません。

■ 試し方
  1. 「受信メール」画面の「取り込み・解析」を押す
     → samples\mails にあるサンプルメール 20 通を取り込み、発注かどうかを判定します。
  2. 「要確認」のメールを開き、発注内容を直して「この内容で確定」または「発注ではない」を押す
  3. 「発注一覧」で登録された発注を確認する
  サンプルのメール・会社名・人名・商品は、すべて架空のものです。

■ AI の接続
  初期設定は AI を使わない「ルールベース」で、この場合は外部と通信しません。
  「設定」画面で AI の接続先（Azure OpenAI・OpenAI・Gemini・Ollama・LM Studio など、
  OpenAI 互換 API）を指定すると、AI で解析します。
  AI の接続先を設定すると、解析するメールの本文などがその接続先に送られます。
  送ってよい情報かどうかは、ご自身の判断でお決めください（利用料金は接続先の規約に従います）。
  Ollama など、ご自身のパソコンで動く AI を指定した場合は、外部には送られません。
  Azure OpenAI は、エンドポイントに https://<リソース名>.openai.azure.com/openai/v1、
  モデルにデプロイ名を入力します。「テスト解析」ボタンで接続を確認できます。

■ 商品マスタ
  明細の品名を商品マスタと照合して、商品コードと標準単価を付けます。
  初回起動時に samples\products.csv（サンプル 38 件）を取り込みます。
  自社の商品マスタは、「設定」画面の「商品マスタ（RAG）」で CSV（列: code, name, aliases, unit, unit_price）
  を指定して取り込みます。

■ データ
  data フォルダに保存されます（ordermail.db：受信メールと発注、settings.json：設定、
  keys：画面の通信の暗号化に使う鍵）。
  data フォルダを消すと初期状態に戻ります。バックアップは data フォルダをコピーしてください。
  API キーとパスワードは、Windows のユーザーごとに暗号化して保存します。

■ 削除（アンインストール）
  黒いウィンドウを閉じてから、展開したフォルダごと削除してください。
  本ソフトウェアは、展開したフォルダの外にファイルを作らず、レジストリも使いません。

■ うまく動かないとき
  ・ブラウザが開かない
      ブラウザで http://localhost:5080 を開いてください。
  ・黒いウィンドウがすぐに閉じる
      別の OrderMail がすでに起動しているか、他のアプリが同じ番号（ポート 5080）を使っています。
      起動中の OrderMail を閉じるか、appsettings.json の "Urls" を書き換えてください
      （例: "http://localhost:5090"）。
  ・画面が操作できなくなった
      黒いウィンドウが閉じていないか確認し、ブラウザの画面を再読み込みしてください。
